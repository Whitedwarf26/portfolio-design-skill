# Portfolio Design Skill · 作品集设计

一个用于 Codex 的中文作品集设计 skill。先讨论思路、确认字体和具体排版，再制作样张与完整作品集。

## 特点

- 先确认要展示的内容、本人职责与呈现方式，按需整合简历信息。
- 封面允许不同构图，保持干净、有序与清楚的层级、对齐。
- 支持商务冷清、可爱圆润与手写编辑感，按目标岗位与个人材料选择。
- 确认标题、正文、英文与手写层级的字体搭配，核实可用字体。
- 讨论封面、章节与案例的具体布局，样张确认后再展开。
- 整理真实作品、版本与业务证据，明确本人职责、AI参与及发布状态。
- 交付可编辑文件与投递PDF，逐页检查阅读与排版。

这是设计工作流程，不是自动生成程序；具体制作依赖使用环境提供的文档、演示、PDF或设计工具。

## 安装

克隆或下载本仓库，将仓库文件夹命名为 portfolio-design，并放入个人 Codex skills 目录。Windows 默认目录为用户目录下 .codex/skills，macOS / Linux 默认目录为 ~/.codex/skills；自定义 CODEX_HOME 时使用其中的 skills 子目录。

若已有同名skill，先比较内容，勿直接覆盖自定义版本。在能够发现此skill的会话中使用 `$portfolio-design`。

## 使用

```text
使用 $portfolio-design 帮我设计求职作品集。
先讨论设计思路、字体和具体排版，确认后再生成样张。
目标岗位：[填写岗位]。
现有材料：[说明或提供文件]。
```

也可以单独请求素材盘点、字体搭配讨论、案例内容优化或已有作品集修改。

## 文件

- SKILL.md：入口与确认流程。
- visual-system.md：视觉、字体与版式规则。
- content-workflow.md：素材与真实案例整理。
- communication-and-layout.md：内容取舍、简历整合、首页构图与字体排列沟通规则。

## 素材与授权

公开版不含个人简历、联系信息、真实业务记录、第三方参考截图或字体文件。字体名称是候选建议，使用前核实当前工具可用性与相应许可。使用者提供的作品和参考保留各自权利，不属于本仓库的MIT授权范围。

## 贡献

欢迎通过Issue或Pull Request提出通用改进。请勿提交私人求职信息、第三方作品文件或凭据；新增流程保持“先讨论并确认，再制作”的原则。
